# Stack Verify

Read-only check. Run from the repo root:

```bash
bash .githooks/stack-verify.sh
```

Exit 0 and `stack-verify: OK` means the manifest is complete. Nested repos
(submodules under a stack) are skipped. ssh and https forms of one URL are
treated as equal.

## Messages and fixes

- `MISSING in manifest` — add a `path;url;status` row to `stacks.csv`.
- `NO URL in manifest` — the row has `-`/empty url but the repo has an
  origin; put the https form of the origin in the row.
- `URL MISMATCH` — make the row url and the repo's `origin` agree
  (fix the row, or `git remote set-url origin ...` in the stack repo).
- `NOTE: listed but not cloned` (stderr, informational) — run
  `.githooks/stack-sync.sh`.

Commit `stacks.csv` after fixing (`stacks.md` is regenerated by the hook).
